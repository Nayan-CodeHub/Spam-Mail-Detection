Connect Gmail

To connect your inbox, add a Google OAuth web-application file named credentials.json to the project root.

  1. Open Google Cloud Console and create or select a project.
  2. Enable the Gmail API.
  3. Create OAuth credentials for a Web application.
  4. Add http://127.0.0.1:5000/oauth2callback as an authorized redirect URI.
  5. Download the JSON file and rename it to credentials.json.
  6. Place it beside requirements.txt, install dependencies, and click Connect Gmail again.

The app requests read-only Gmail access. It never sends, deletes, or changes messages.
